# Changelog

## 1.0.0 - 2026-10-07

- Native GTK4 sticky-note checklist with atomic local persistence.
- Multiline notes with `Shift+Enter` and fixed-width wrapping.
- Floating Hyprland integration without special workspaces or focus stealing.
- Resident show, hide and toggle commands.
- Waybar pending-note counter and tray integration.
- Fast checkbox burst animation when completing a task.
- XDG desktop entry and scalable icon for application launchers.
- Arch Linux/AUR packaging.
